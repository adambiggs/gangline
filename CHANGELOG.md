# Changelog

## [0.10.0](https://github.com/adambiggs/gangline/compare/gangline-v0.9.0...gangline-v0.10.0) (2026-09-19)


### ⚠ BREAKING CHANGES

* `gang alerts` is gone and commands no longer print `gang: last tick failed: ...` on stderr; read tick failures from `gang roster`, `gang status` or the team's tick.log.
* **drop:** gang safe-to-drop and gang drop --orphan are removed, and roster --porcelain no longer prints the teardown column.
* **hitch:** gang hitch --tier is removed and the startup brief no longer carries a tier line.
* **gate:** test/gate.sh no longer supports --snapshot, --assert-owned, or --assert-unmoved; it runs fast lint and smoke on the working tree.
* **send:** gang send no longer accepts --ack or --no-reply and the hidden reply-obligations and reply-released commands are gone; drop those flags from callers.
