# ADR-0042: Doctrine is the operator's, and every hitch carries it

## Context

Agent lifecycle actions span tmux and host processes, so partial success can leave live
or durable state.

## Decision

Core owns one optional doctrine slot and ships no content.

## Consequences

Deliver its validated prose in every hitch contract because Gangline cannot observe
which caller is an operator; scope belongs in the operator's words, not an inferred
role. Adoption still injects no startup text.
