gangline

Native coding agents. One local tmux substrate.

demo start surface long sessions github

Gangline runs Claude Code, Codex, OpenCode, and Pi as named windows in one tmux session. Each keeps its native terminal, tools, permissions, subscription, and context. Gangline provides lifecycle, attributed verified delivery, direct observation, and native compaction.

It is substrate, not an agent coordinator. There is no task graph, role doctrine, deadline manager, patrol, daemon, database, watchdog, or cloud agent swarm. The operator and native harnesses remain in control.

Demo

One goal, two native Codex sessions. The worker's attributed report starts the lead's next turn; delivery, pane output, and final state are real.

Start

curl -fsSL https://raw.githubusercontent.com/adambiggs/gangline/main/install.sh | sh

cd ~/your/repo
gang up
gang hitch worker -p codex -d "$PWD"

gang send --to worker --stdin <<'TASK'
Fix the failing parser test and report the proof.
TASK

gang roster

The surface

  • gang up, gang hitch, gang adopt, gang attach, gang drop, and gang down control native tmux windows.
  • gang send derives the sender inside the team and reports success only after the target composer visibly accepts and submits the message.
  • gang status, gang roster, and gang capture expose conservative current state.
  • gang compact invokes the harness's own compaction mechanism.
  • gang cutoff declares one optional team deadline and exposes yellow and red advisory edges without enforcing it.
  • gang profiles lists the available harness integrations.
  • Profiles contain harness-specific launch syntax, native hooks, and TUI observation. The core has no harness-name branches.

Long sessions

Agents get one short startup contract: their name, how to send an attributed message, and how to request native compaction. Codex self-compaction crosses its native Stop boundary so /compact is submitted only after the requesting turn releases the composer.

Optional context lights are off by default. When enabled, their absolute yellow and red thresholds should be intentionally high so agents retain most of their native context and can self-compact before native automatic compaction:

GANG_CONTEXT_LIGHTS=210000,225000 gang hitch worker -p codex

The lights are advisory and edge-triggered. The agent decides when to compact.

A team may also declare a wall-clock cutoff. Yellow appears halfway through the declared span and red after four-fifths; nothing stops automatically.

gang cutoff 2h

One Bash CLI over tmux. No daemon, message bus, private protocol, or silent fallback. State dies with its window or team.
