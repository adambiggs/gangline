gangline

Native coding agents. One local tmux substrate.

start surface long sessions github

Gangline runs Claude Code, Codex, OpenCode, and Pi as named windows in one tmux session. Each keeps its native terminal, tools, permissions, subscription, and context. Gangline provides lifecycle, attributed verified delivery, direct observation, and native compaction.

It is substrate, not an agent coordinator. There is no task graph, role doctrine, deadline manager, patrol, daemon, database, watchdog, or cloud agent swarm. The operator and native harnesses remain in control.

Start

curl -fsSL https://raw.githubusercontent.com/adambiggs/gangline/main/install.sh | sh

cd ~/your/repo
gang up
gang hitch worker -p codex -d "$PWD"

gang send --to worker --stdin <<'TASK'
Fix the failing parser test and report the proof.
TASK

gang roster

The surface

  • up, hitch, adopt, attach, drop, and down control native tmux windows.
  • send derives the sender inside the team and reports success only after the target composer visibly accepts and submits the message.
  • status, roster, capture, and wait expose conservative current state.
  • compact invokes the harness's own compaction mechanism.
  • Profiles contain harness-specific launch syntax, native hooks, and TUI observation. The core has no harness-name branches.

Long sessions

Agents get one short startup contract: their name, how to answer an attributed message, and how to request native compaction. Codex self-compaction crosses its native Stop boundary so /compact is submitted only after the requesting turn releases the composer.

Optional context lights are off by default. An operator may set absolute yellow and red thresholds at hitch time:

GANG_CONTEXT_LIGHTS=120000,200000 gang hitch worker -p codex

The lights are advisory and edge-triggered. The agent finishes a coherent arc, records durable state in the repository, and compacts at a natural checkpoint.

One Bash CLI over tmux. No daemon, message bus, private protocol, or silent fallback. State dies with the window.
